# flutterlane
FlutterLane 是一款Flutter 桌面端专属、自研泳道分层 IDE 级布局引擎。摒弃传统 Flex/Stack 普通布局思维，独创「泳道+分组+标签快照」三层布局架构，复刻 VSCode + Chrome 双端交互范式，专为桌面端复杂工作台、IDE、可视化编辑器场景打造。
提供零布局侵入的注册式开发体系，业务仅需注册视图、专注业务UI开发，框架全权托管拖拽、Resize、折叠、滚动、多布局快照、本地持久化等所有底层能力，无任何第三方后端依赖、能力完全内聚，是 Flutter 桌面端高自由度自定义布局的一站式独立开源解决方案。
